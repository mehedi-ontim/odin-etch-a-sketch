# Etch-a-Sketch

A browser-based sketchpad built as part of
The Odin Project Foundations curriculum.

## Features

- Dynamically generated 16 × 16 grid
- Mouse-hover drawing
- Adjustable grid dimensions (1–100)
- Automatic clearing when resizing
- Responsive sketchpad layout using Flexbox

## How to Use

1. Open `index.html` in a browser.
2. Move your mouse across the grid to draw.
3. Click "Change Grid Size" to create a new grid.
4. Enter a number between 1 and 100.
5. Start drawing on the new sketchpad.

## Built With

- HTML
- CSS Flexbox
- JavaScript
- DOM manipulation
- Event listeners
